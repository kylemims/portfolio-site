# Kyle Mims – Portfolio Website

Welcome! This is the official portfolio site of [Kyle Mims](https://www.kylemims.dev) — a creative technologist, full-stack web developer, and brand designer based in Nashville, TN.

This site is a curated space to showcase my development projects, creative work, and technical experiments as I transition from 13 years in boutique fitness entrepreneurship into the world of tech and product design.

---

## 🚀 Live Site

🌐 [https://www.kylemims.dev](https://www.kylemims.dev)

---

## 🛠️ Built With

- **React** – Front-end framework
- **Vite** – Lightning-fast bundler and dev server
- **Pure CSS** – The fun part
- **Custom SVG assets** – Created in Adobe Illustrator
- **Hosted on** – [Netlify](https://www.netlify.com/)
- **Domain** – Managed via Netlify DNS

---

## 📁 Projects Featured

- **Bash Stash** – Dev productivity tool to generate project boilerplates, bash scripts, and styling presets (coming soon)
- **Pick-A-Park** – National Park trip planner using NPS API + custom trip logic
- **Punk Pizza** – Dynamic pizza ordering system with inventory, Stripe payments, and admin dashboards

Each project card links to a deployed app and corresponding GitHub repo.

## 📸 Visual Identity & Design Goals

The site was intentionally designed to reflect my aesthetic:
- Minimalist layout with bold typography
- Custom-designed monogram logo (NR)
- Emphasis on both code *and* visual design
- Mobile-first layout with smooth transitions and animations
